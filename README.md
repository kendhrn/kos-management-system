# Kos Management System

A web application for managing a boarding house (kos): rooms, tenants, rent billing, expenses, and financial reports.

## Features (planned)

- Dashboard with occupancy and monthly income/expense overview
- Room and tenant management (check-in, check-out, deposit)
- Rent billing with due-date reminders via WhatsApp
- Income and expense tracking
- Financial reports with Excel/PDF export

## Tech Stack

- [Next.js](https://nextjs.org/) (React + TypeScript)
- [Supabase](https://supabase.com/) (PostgreSQL database + authentication)
- [Tailwind CSS](https://tailwindcss.com/)
